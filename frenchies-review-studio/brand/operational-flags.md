# Operational Flags — systemic issues to surface

After drafting responses, the model scans the review for signs of a *systemic*
issue the owner should know about. These are for internal awareness only — never
part of the public reply. Edit this list to match what you want watched.

Each flag has a severity: **low** (worth noting), **medium** (recurring or
customer-impacting), **high** (safety, legal, health, or reputation risk).

- **Extension / enhancement durability** — polish, gel, or dip lifting/chipping
  early. (low–medium)
- **Service completeness** — steps skipped, rushed, or cut short. (medium)
- **Timing / wait** — long waits, running behind, appointments not honored. (medium)
- **Booking / communication** — no-shows on the salon side, unreturned messages,
  scheduling confusion, rudeness at the desk. (medium–high)
- **Pricing transparency** — surprise at final cost, add-ons not disclosed. (medium)
- **Cleanliness / sanitation concern** — any hint of unsanitary practice. (high)
- **Injury / health harm** — cuts, infection, reaction, pain. (high)
- **Technician-specific pattern** — the same tech named across multiple
  complaints. (medium–high)
- **Product / allergy** — reaction to a product; note but don't diagnose. (medium)
- **Accessibility / comfort** — seating, mobility, sensory (odor) concerns. (low–medium)
